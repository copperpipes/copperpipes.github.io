# Copper Pipes — передача проекта

Готовый исходник сайта для локального запуска, доработки и публикации.

## Требования

- Node.js 22.13 или новее
- pnpm

## Запуск локально

```bash
pnpm install
pnpm dev
```

После запуска открыть адрес, который появится в терминале (обычно `http://localhost:3000`).

## Проверка production-сборки

```bash
pnpm build
pnpm start
```

Папка `dist/` уже содержит проверенную production-сборку. Если хостинг принимает готовый Cloudflare Worker/Vite build, пересобирать проект не обязательно.

## Где находится сайт

- `public/copper-pipes.html` — основной сайт: разметка, стили, анимации и интерактивность.
- `public/copper-pipes-icon.png` — знак Copper Pipes.
- `app/page.tsx` — оболочка, которая выводит основной сайт на весь экран.
- `.openai/hosting.json` — конфигурация проекта для OpenAI Sites.

Сейчас проект не требует переменных окружения или отдельной базы данных. Для изменений дизайна и контента в первую очередь редактировать `public/copper-pipes.html`.
